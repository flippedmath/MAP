Unlocked Teacher benefits

A Teacher account is unlocked when it has at least one credit balance, or at least one unreimbursed student seat. Unlocking enables paid teaching features beyond the free trial:

  • Create more than one course (locked teachers are limited to a single course)
  • Send student invites (each invite spends one seat credit)
  • Create and use private collaboration groups (Public Library stays available while locked)
  • Print tests and generate printouts from the Course Assessments gear (unlocked teachers)

Voiding unused invites or removing a student within 7 days reimburses a credit and can relock the teacher if balance and unreimbursed seats both return to zero.
